# Desafio: Análise de Fala e Linguagem com Azure Speech Studio e Language Studio

## 📚 Visão Geral

Este repositório contém um resumo prático do desafio proposto pela DIO com o objetivo de explorar os recursos do **Azure Speech Studio** e do **Language Studio**, duas ferramentas baseadas em inteligência artificial voltadas para o **processamento de fala e linguagem natural**.

Durante os estudos, foram apresentados conceitos fundamentais sobre como essas plataformas podem ser usadas para:

- Transcrever áudios para texto automaticamente (Speech-to-Text);
- Gerar áudio a partir de texto com vozes sintéticas (Text-to-Speech);
- Traduzir automaticamente falas em tempo real;
- Analisar textos com IA para extrair **frases-chave**, **sentimentos**, **entidades nomeadas** e muito mais;
- Criar bases de conhecimento para integração com bots e assistentes virtuais.

---

## 🎥 O que aprendi com os vídeos

1. **Azure Speech Studio**:
   - É uma plataforma da Microsoft para trabalhar com **voz**;
   - Possui funcionalidades como: transcrição automática de fala, conversão de texto em voz, tradução de áudio e personalização de modelos de voz;
   - Útil para criar soluções acessíveis e interativas baseadas em comando de voz.

2. **Language Studio**:
   - Permite análise de textos com IA;
   - Possui recursos como: **Análise de Sentimento**, **Extração de Frases-Chave**, **Detecção de Idioma** e **Classificação de Texto**;
   - Serve para enriquecer experiências de chatbot, atendimento automatizado, análise de feedback de clientes e muito mais.
